# 🗑️ SmartBin - Giải pháp phân loại rác thông minh

## 📖 Thông tin chung
- **Môn học:** Nhập môn AIoT
- **Chủ đề:** T1 - Phân loại rác thải bằng AI

## 💡 Ý tưởng cốt lõi
Hệ thống sử dụng camera và mô hình AI (Teachable Machine) để tự động nhận diện các loại rác tại nguồn (Nhựa, Giấy, Kim loại...), kết hợp âm thanh hướng dẫn người dùng bỏ rác đúng quy định.

## 🚀 Tính năng dự kiến
- Quét và nhận diện rác realtime.
- Cảnh báo âm thanh bằng Text-to-Speech.
- Hiển thị Confidence Score.
